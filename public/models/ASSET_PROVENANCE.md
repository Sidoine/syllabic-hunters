# Map model assets

- `reading-tree.glb` — generated from `reading-tree-reference-opaque.png` with the local ComfyUI TRELLIS.2 image-to-model workflow. The Boolean node **Boolean (Switch to Trellis2)** was set to `true`; the GLB includes embedded textures, a 1,024-pixel bake, and a 50,000-face runtime mesh.
- `reading-bookstone.glb` — generated from `reading-bookstone-reference-opaque.png` with the local ComfyUI TRELLIS.2 image-to-model workflow. The opaque reference avoids the empty foreground mask from the transparent variant; the GLB includes embedded textures, a 1,024-pixel bake, and a 50,000-face runtime mesh.
- `math-abacus.glb` — generated from `math-abacus-clean-gray.png` with the local ComfyUI TRELLIS.2 image-to-model workflow. The Boolean node **Boolean (Switch to Trellis2)** was set to `true`; the GLB includes embedded textures, a 1,024-pixel bake, and a 50,000-face runtime mesh.
- `math-crystals.glb` — generated from `math-crystals-clean.png` with the local ComfyUI TRELLIS.2 image-to-model workflow. Its 147-million-face raw shape exceeded the bake's VRAM budget, so the bake reference was changed to the decimated mesh; the bake succeeds with a 50,000-face runtime mesh and 1,024-pixel texture.
- `forest-tree.glb` — generated from the ImageGen reference `reading-forest-tree-reference.png` with TRELLIS.2. The remesh resolution is 320, smoothing is reduced, and the runtime mesh is 30,000 faces so it can be instanced through the forest.
- `mountain-fir.glb` — generated from the ImageGen reference `mountain-fir-reference.png` with TRELLIS.2 using the same low-detail remesh and 30,000-face target for repeated placement on mountain slopes.

- `forest-understory.glb` — generated from the ImageGen reference `forest-understory.png` with local TRELLIS.2; 1,024 shape resolution, 1,024-pixel texture bake, and a 15,000-face runtime target for repeated ground cover.
- `mossy-boulders.glb` — generated from `mossy-boulders.png` with local TRELLIS.2; 1,024 shape resolution, 1,024-pixel texture bake, and a 15,000-face runtime target.
- `storybook-cottage.glb` — generated from `storybook-cottage.png` with local TRELLIS.2; 1,024 shape resolution, 1,024-pixel texture bake, and a 15,000-face runtime target.
- `mountain-observatory.glb` — generated from `mountain-observatory.png` with local TRELLIS.2; 1,024 shape resolution, 1,024-pixel texture bake, and a 15,000-face runtime target.
- `creek-segment.glb` — generated from `creek-segment.png` with local TRELLIS.2; 1,024 shape resolution, 1,024-pixel texture bake, and a 15,000-face runtime target. Repeated as connected creek sections along the map's south edge.
- `creek-open-segment-v2.glb` — generated from `src/assets/3d/river-open-segment-reference-v2.png` with the local TRELLIS.2 workflow (Boolean **Switch to Trellis2** enabled), decimated to 30,000 faces, and resized to 1,024-pixel embedded textures. The narrow open channel runs along local Z and is placed as overlapping, tangent-aligned sections along the map's winding river.
- `map-forest-flower-patch.glb` — generated from the ImageGen reference `src/assets/3d/references/forest-flower-patch.png` with the local TRELLIS.2 workflow (Boolean **Switch to Trellis2** enabled), decimated to 25,000 faces with 1,024-pixel textures. Repeated as compact flower-and-fern beds in both regions.
- `map-riverbank-rock-cluster.glb` — generated from `src/assets/3d/references/riverbank-rock-cluster.png` with local TRELLIS.2, decimated to 45,000 faces with 1,024-pixel textures. Instanced in pairs along the creek banks.
- `map-woodland-footbridge.glb` — generated from `src/assets/3d/references/woodland-footbridge.png` with local TRELLIS.2, decimated to 70,000 faces with 1,024-pixel textures. Oriented across the reading trail where it crosses the creek.

The ground textures `public/textures/forest-ground.png` and `public/textures/mountain-ground.png` were generated with ImageGen as seamless albedo tiles. The terrain is a continuous Three.js height-field mesh; a world-position shader blends the forest and mountain textures across the region boundary. Tree and prop references and intermediate ComfyUI outputs are kept locally under `src/assets/3d/` and excluded from Git. The concept illustration remains a style reference rather than a flat map texture. The former hand-built lantern posts were removed in favor of textured scene assets.
